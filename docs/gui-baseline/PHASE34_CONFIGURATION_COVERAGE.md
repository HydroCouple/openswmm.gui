# Phase 34 configuration coverage and remaining gates

This is an implementation-chain review under W4/W4a/W4d and C1–C5/C7, not a claim that every visualization is release-certified. The historical inventory in `SURFACES.md` remains the complete family list. Test counts and packaging evidence belong in the final Phase 34 delivery report.

## Shared contracts implemented in this batch

- Classification edits remain drafts until all entered breaks/ranges are finite, ordered and valid for the chosen method. Editing one value preserves untouched precision. Changing chrome theme preserves scientific colour definitions.
- A layer style session restores on Cancel, Escape and window close. Apply establishes the retained state; a completed session contributes one undo action. Snapshots route by stable subject ID and include sublayer structure, order, visibility, opacity and style. General controls only write fields the user edited. Arbitrary external simultaneous symbology writers and CRS reassignment are separate unresolved transaction concerns.
- File-backed cell variables have semantic keys combining domain, dataset, species name and explicit sigma layer where applicable. Source/run identity belongs to the owning results layer. Numeric species row positions are never serialized. Reopening a different species order re-resolves names. An unavailable saved variable remains unavailable.
- Additional result sublayers independently configure classification, visibility, opacity and missing/waterless/not-applicable colours. CPU and QSG fills share the same colour resolver. Groundwater validity is independent of the surface wet mask. These are flat cell values; no unsupported scalar-to-vector reconstruction is implied.
- The default range for additional fields is current-frame. Whole-run range scans all available reported frames, computes exact extrema and retains a deterministic reservoir of at most 32,768 valid samples for statistical classification. Samples are approximate, not an exhaustive quantile/Jenks calculation. Explicit ranges do not trigger a scan. Whole-run classification is refused for a still-live source. At most eight frames / 64 MiB and sixteen bounded range summaries are cached; source revision/history/time-count changes invalidate them. Visible render passes additionally retain their immutable presented frames so legend ranges match the displayed geometry while asynchronous work is pending.
- Units come from file metadata. Surface species use per-species units. Generic groundwater concentration `units=1` does not establish concentration units. Unknown-unit fields may be inspected and displayed with an explicit label; scientific CSV export requires established units. No implicit coordinate-unit conversion is applied to concentrations, storage or exchange rates.
- Missing/nonfinite/fill values, waterless zones and not-applicable sigma closures are separate states. A numerical zero alone never establishes missing/waterless data. Held groundwater fluxes retain their temporal designation.
- The generic current-frame CSV contains source/key/dataset/species/domain/zone/layer/time/cell/value/status/units, preserves native values, protects the source from path aliases and publishes atomically.

## Icon evidence

The effective main-window catalog is authoritative: registered Designer icons are rebound through IconFactory. Phase 34 adds `actionPick2DCells` to that catalog and gives the action a meaningful accessible name. Five SVGs were revised: groundwater parameters, groundwater initial state, cell selection, polygon selection and GIS import. Before/after sheets cover light/dark, normal/disabled/selected and native 16/20/24/32 sizes plus DPR2. All 204 registered SVG resources are inspected by the integrity test; the two intentional full-colour rule-status badges are explicit exceptions. Contact sheets and retain/replace rationale are in the batch artifacts and `workplans/phase34_icons_notes.md`.

## Explicit completion boundary

This batch closes tested classification/session defects and establishes a usable file-backed scalar-species chain through configuration, rendering, legend, inspection, persistence and CSV. It does not certify all of W4/W4a: arbitrary species contours/labels, generic GIS raster/vector export, live species streaming and engine unit/runtime gates remain. They are retained requirements, not silently treated as completed or multiplied into new micro-phases. Phase 35 consumes the descriptor contracts; Phase 36 combines native/performance/release acceptance and remaining visualization integration with the meshing owner’s evidence.
