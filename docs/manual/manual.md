@page user_manual User Manual

Welcome to the **OpenSWMM GUI** user manual. OpenSWMM GUI is a Qt6/C++ GIS-based
graphical user interface for building, running, and visualizing SWMM 6.0
storm-water models with the next-generation OpenSWMM engine.

The chapters below walk through the application from first launch to advanced
results analysis. They are ordered for a first read-through, but each chapter
also stands on its own as a reference.
