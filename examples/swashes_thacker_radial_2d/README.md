# Thacker: Radial Paraboloid Oscillation (SWASHES 4.2.2)

SWASHES case `thacker-radial-2d` -- "Thacker radially-symmetric paraboloid
oscillation".

Frictionless water sloshing in a radially symmetric paraboloid basin, a
periodic analytic solution with a continuously moving shoreline. Tests 2D
wetting and drying. 2D only.

Analytical benchmark from Delestre et al. (2013), *SWASHES: a compilation of
shallow water analytic solutions for hydraulic and environmental studies*,
International Journal for Numerical Methods in Fluids 72(3):269-300, doi
[10.1002/fld.3741](https://doi.org/10.1002/fld.3741), SWASHES 4.2.2 (radial).

## What ships here

| File | Purpose |
|---|---|
| `2d_explicit.inp` | 2D shallow-water mesh, explicit local-inertial integrator -- opened by default |
| `reference.csv` | Analytic solution, columns `t_s,x_m,h_m,q_m2_per_s` |
| `example.json` | Welcome-screen display metadata |

Input files only. Results (`.out`, `.rpt` and `surface.h5`) are written next
to the copied `.inp` when you run, never into the bundled baseline.

## Comparing against the analytic solution

`reference.csv` tabulates depth `h` and unit discharge `q` on a grid refined
20x relative to the model, at the comparison times listed above. Run a deck,
export the depth profile along the channel at one of those times, and plot it
against the matching `t_s` rows.

## Provenance

The decks were generated by the SWASHES suite of the openswmm.engine
benchmarks (`swasheslib.gen1d` / `swasheslib.gen2d`) and imported by
`scripts/import_swashes_examples.py`. All SWASHES decks use SI units
(`FLOW_UNITS CMS`) and share one normalized `[OPTIONS]` block so that solver
columns differ only in the routing scheme.

`reference.csv` is an independent Python reimplementation of the published
closed-form solutions (`swasheslib/analytic.py`); no output of the CeCILL-V2
SWASHES tool is vendored here.
