The fifteen-minute head, depth and velocity fields exactly match the original
saved GUI run. Tests consume only fixed data: no engine or HDF5 dependency is
needed to run the geometry regressions. Do not regenerate this fixture merely
to accommodate a changed reconstruction or a changed engine result.

The original fitter produces negative corners in all 80 otherwise-wet flat
cells at 440 < centroid x < 480 m at fifteen, thirty and sixty minutes. At one
hour these cells store 10.70-10.93 mm, while displayed corners span -5.05 to
26.81 mm. The 360-to-370-second transition changes one fitted corner by 6.85 mm
when its stored depth changes only 0.03058 mm.

Tests require supported wet depths, no large invented peaks, display-policy
independence, a bounded onset transition, and conserved fitted storage.
