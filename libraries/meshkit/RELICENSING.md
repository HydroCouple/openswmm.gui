# Apache 2.0 authorization and scope

On 2026-10-29 the project rights holder explicitly confirmed: “Yes, I hold the
rights and authorize relicensing” for all non-third-party MeshKit code, including
earlier contributions, and selected Apache 2.0 in the same review conversation.
This is the authorization for updating MeshKit source notices and LICENSE.

The grant covers this `libraries/meshkit` project: standard C++ algorithms,
codecs, Python bindings, optional Qt adapters, tests and documentation. Existing
copyright notices remain. Vendored robust predicates retain their own notice;
third-party runtimes are excluded. The parent GUI's license is unchanged.
Earlier revisions distributed under GPL keep that existing grant.

The original extraction inventory remains in PROVENANCE.md. Local author
metadata was not used as a substitute for the rights holder's authorization.
The release includes LICENSE and NOTICE. No public package/repository upload is
performed by this local preparation.
